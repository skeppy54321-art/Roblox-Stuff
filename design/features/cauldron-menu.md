# Cauldron menu

Status: draft (built overnight, not yet reviewed)

* **Goal:** choose which potion to brew without a separate screen.
* **When:** only while you stand within ~13 studs of your own cauldron, it isn't brewing, and no panel is open.
* **Layout:** bottom-center card strip (scrolls sideways). Card = bottle icon, name, ingredient dots with have/need, status pill.
* **States per card:** can brew (green "BREW [n]"), missing (grey "Need Moonberry", counts in red), shelf full (grey "SHELF FULL"), wanted by a customer (gold "WANTED" ribbon), suggested (gold outline = what pressing E brews).
* **Input:** tap/click a card, or keys 1-9. Server checks everything again.
