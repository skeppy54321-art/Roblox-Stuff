# Upgrades panel and Recipe Book

Status: draft (built overnight, not yet reviewed)

## Upgrades panel
* Scrolling list of cards: colored level badge, name, description, "now -> next" line, level pips, buy button.
* Buy button states: affordable (green, cost), too expensive (grey, cost), needs another upgrade first (grey, "Needs Starflower Bed"), maxed (gold "MAXED").
* Buying shows a celebration banner and changes the shop in the world.

## Recipe Book
* Scrolling list of every potion: bottle, name, what it does, ingredient chips, coins and brew time.
* Status tag: "NEW! Try it" (unlocked, never brewed), "Brewed!", or "Needs <upgrade>" (locked, card greyed out).
